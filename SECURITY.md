# Security policy

For a potential vulnerability, use [private vulnerability reporting](https://github.com/Ky1eYang/microcrab-agents/security/advisories/new) if enabled, or contact the repository maintainers privately via GitHub. Do not post secrets, private Host paths, session transcripts, or details that would put users at risk in a public issue.

Include the exact Agent and Core revisions, host type, and the smallest synthetic example that demonstrates the issue. A Component's compatibility and permissions are determined by the host Runtime and its configuration, not by the repository branch alone.
